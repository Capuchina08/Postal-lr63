📬 Postal Digital

Proyecto para la creación de una postal digital interactiva, desarrollada con tecnologías web. Permite mostrar un mensaje personalizado acompañado de diseño visual, ideal para felicitaciones, invitaciones o mensajes especiales.

🚀 Características

🎨 Diseño moderno y responsivo

✉️ Mensaje personalizable

🖼️ Soporte para imágenes y estilos CSS

💻 Compatible con navegadores modernos

🌐 Desplegable en GitHub Pages

🛠️ Tecnologías utilizadas

HTML5 – Estructura del contenido

CSS3 – Estilos y diseño visual

JavaScript – Interactividad y personalización

📂 Estructura del proyecto
postal-digital/
│── index.html
│── styles.css
│── script.js
│── assets/
│   └── images/
│── README.md
⚙️ Instalación y uso

Clona el repositorio:

git clone https://github.com/tu-usuario/postal-digital.git

Accede a la carpeta del proyecto:

cd postal-digital

Abre el archivo index.html en tu navegador.

🌍 Despliegue en GitHub Pages

Ve a Settings > Pages en tu repositorio.

Selecciona la rama main y la carpeta /root.

Guarda los cambios y accede
